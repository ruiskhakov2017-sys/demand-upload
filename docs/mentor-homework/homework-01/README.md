\# Homework 01 — Axyro Project Review



\## Цель



Изучение структуры реального проекта Axyro и основных инженерных процессов разработки.



В рамках задания были разобраны:



\- инструменты разработки;

\- структура backend-приложения;

\- базы данных и хранилища;

\- фоновые задачи;

\- интеграции;

\- тестирование и CI.
